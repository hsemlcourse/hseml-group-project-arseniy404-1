## Описание задачи

**Цель:** предсказать рейтинг (сложность) алгоритмической задачи с платформы Codeforces по её метаданным: количеству решений, тегам, тексту условия, названию и т.д.

**Тип задачи:** регрессия

**Источник данных:** самостоятельно разработанный парсер (см. `src/parser.py`), собирающий задачи через официальный API и парсинг страниц задач.

---

## Метрика качества

Основная метрика – **MAE (Mean Absolute Error)** – средняя абсолютная ошибка предсказания в единицах рейтинга.

**Почему MAE?**
- Интерпретируема: ошибка в 100 пунктов означает, что модель в среднем ошибается на 100 единиц рейтинга.
- Устойчива к выбросам (в отличие от MSE).
- Позволяет легко сравнивать модели на единой шкале.

Дополнительно используются **RMSE** (для анализа крупных ошибок) и **R²** (доля объяснённой дисперсии).

## Данные

**Исходные данные:**  
- Собрано 1500 задач с Codeforces (после удаления дубликатов и пропусков).  
- Каждая задача содержит: `contestId`, `index`, `name`, `rating` (целевая переменная), `tags`, `solvedCount`, `statement` (текст условия).

**Предобработка и признаки (18 шт.):**
- **Числовые признаки:**  
  `solvedCount` (исходное кол-во решений), `log_solved` (логарифм для нормализации),  
  `n_tags` (количество тегов),  
  `statement_length`, `statement_words` (длина условия),  
  `has_math` (наличие формул `$...$`),  
  `name_length`, `name_words` (длина названия).

- **Категориальные (one‑hot):**  
  Топ‑10 наиболее частотных тегов: `binary search`, `constructive algorithms`, `brute force`, `greedy`, `bitmasks`, `combinatorics`, `data structures`, `dp`, `math`, `implementation`.

**Разбиение данных:**  
- **По контестам** – все задачи из одного соревнования попадают в одну выборку. Это предотвращает утечку данных (задачи одного контеста имеют похожие стили и темы).  
- Train / Val / Test: 70% / 15% / 15% контестов → 1016 / 214 / 239 задач.

**Пропуски:** отсутствуют.  
**Выбросы:** проверены методом IQR, оставлены как реальные аномалии (очень сложные или вирусные задачи).

## Результаты

Ниже представлены результаты экспериментов. Лучшая модель – **Voting Ensemble** (Ridge + Random Forest + XGBoost).

| Модель                | Val MAE | Test MAE | Val R²  | Примечание                                  |
|-----------------------|---------|----------|---------|---------------------------------------------|
| Dummy (медиана)       | 312.4   | 308.1    | –       | Тривиальный бейзлайн                        |
| Linear Regression     | 185.3   | 183.9    | 0.8645  | Без регуляризации                           |
| Ridge (α=0.1)         | 185.3   | 183.8    | 0.8645  | L2-регуляризация                            |
| Lasso (α=0.1)         | 188.1   | 186.5    | 0.8615  | L1, обнулил 3 признака                      |
| Random Forest (best)  | 174.2   | 172.5    | 0.8802  | max_depth=20, n_estimators=200              |
| XGBoost (best)        | 171.8   | 170.9    | 0.8834  | max_depth=6, lr=0.1, n_estimators=300       |
| **Voting Ensemble**   | **168.5** | **167.2** | **0.8871** | Ridge + RF + XGBoost                     |

**Выбор финальной модели:** Voting Ensemble дал наименьшую MAE на валидации и тесте, устойчив к переобучению (разрыв между валидацией и тестом минимален). Ансамбль сочетает преимущества Ridge (работа с мультиколлинеарностью), Random Forest (нелинейности) и XGBoost (сложные взаимодействия).

**Улучшение относительно бейзлайна:** MAE снижена с 312 до 167 – относительное улучшение на 46%.
